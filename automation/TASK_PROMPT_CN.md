# 云端任务入口

所有任务先读取最新 main 的 automation/EXECUTION_RULES_CN.md 并按其执行。每日任务处理 articles、forum、docs，周任务只处理events。只生成草稿，checked模式下在完整校验通过后普通PR合并。任务时间及实际保存状态以 ChatGPT Scheduled 为准。

文章与论坛执行2026-10-09“简单直接的事件写法”：点名具体事件和矛盾，直接追问原因、依据或处理结果，减少抽象问卷和偏好二选一；未核实指控明确归属，保留事实核验。知识库保持解释型写法。详细规则见EXECUTION_RULES_CN.md及对应plans。
